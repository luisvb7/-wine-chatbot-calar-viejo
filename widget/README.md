# 🌐 Widget de Integración Web

Esta carpeta contiene los archivos necesarios para integrar el chatbot en la web de Marín Perona.

## 📁 Archivos en esta carpeta:

1. **`widget-chatbot.js`** → Widget flotante completo (archivo principal)
2. **`ejemplo-widget.html`** → Página de demostración del widget
3. **`INSTRUCCIONES-WIDGET.md`** → Guía completa de instalación paso a paso

## ⚠️ IMPORTANTE

Estos archivos **NO** son necesarios para ejecutar el chatbot en Streamlit Cloud.

- ✅ **Streamlit Cloud** ejecuta solo `wine_chatbot_app.py` (en la raíz del proyecto)
- 📦 **Estos archivos** son para descargar e instalar en tu web marinperona.es

## 🚀 Uso Rápido

1. Descarga `widget-chatbot.js`
2. Súbelo a tu web en `/js/`
3. Añade en tu HTML: `<script src="/js/widget-chatbot.js"></script>`

Ver `INSTRUCCIONES-WIDGET.md` para más detalles.
